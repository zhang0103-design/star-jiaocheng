# 代理 IP 新手快速开始

这篇文章帮你在几分钟内完成第一次代理配置。先确认信息，再选平台操作，最后验证结果。

## 第 1 步：获取代理信息

从你的代理服务商那里拿到连接信息。通常包含四样：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| IP | 代理服务器地址 | `23.27.210.62` |
| 端口 | 连接端口 | `6432` |
| 用户名 | 登录账号（可选） | `your_user` |
| 密码 | 登录密码（可选） | `your_pass` |

::: warning 重要：别只看字符串猜协议
服务商给你的可能是一串 `ip:port:user:pass` 格式的信息，**这串字符本身不能判断代理协议**。是 SOCKS5 还是 HTTP，必须以服务商明确标注的信息为准，不要凭格式自行猜测。
:::

## 第 2 步：确认代理协议

查看服务商提供的信息，确认是 **SOCKS5** 还是 **HTTP**。客户端里选择的协议必须和服务商标注的一致，否则会连接失败。

## 第 3 步：识别四个字段

把 IP、端口、用户名、密码四个字段分别对应填入客户端：

- **IP** 填到「服务器 / Server」一栏；
- **端口** 填到「端口 / Port」一栏；
- **用户名、密码** 填到「用户名 / 密码」或「认证 / Auth」一栏（没有就留空）。

## 第 4 步：选择平台教程

根据你使用的设备，进入对应教程：

- [Android 手机链式代理配置教程](/mobile/android-chain)
- [iOS 链式代理配置教程](/mobile/ios-chain)

## 第 5 步：完成配置

按教程步骤填好代理信息，保存并启动连接。

## 第 6 步：测试最终出口 IP

连接成功后，打开任意 IP 查询网站（如 ip2location.com），查看页面显示的 IP：

- **显示的 IP 与你的代理 IP 一致** → 配置成功；
- **显示的 IP 不对** → 说明链路或出口设置有问题，参考[连接失败排查](/help/troubleshooting)。
