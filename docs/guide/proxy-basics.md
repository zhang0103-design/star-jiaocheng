# 代理 IP 基础知识

只讲配置代理 IP 必须知道的几个概念，用最通俗的话说清楚。

## 什么是代理 IP

代理 IP 是一台**中转服务器**。你的设备先连到这台服务器，再由它去访问目标网站。对目标网站来说，看到的是代理服务器的 IP，而不是你本机的 IP。

## SOCKS5 是什么

**SOCKS5** 是一种代理协议，能转发任意类型的网络流量（网页、应用等），通用性最强。大多数代理客户端和业务场景都用它。

## HTTP 是什么

**HTTP 代理**主要针对网页浏览场景。相比 SOCKS5，它通常只处理 HTTP/HTTPS 流量，适用范围更窄。

::: tip 一句话区分
不确定用哪个时，优先选 **SOCKS5**；如果服务商明确标注是 HTTP，就按 HTTP 填。
:::

## IP、端口、用户名、密码分别是什么

- **IP**：代理服务器的地址，相当于「门牌号」。
- **端口**：服务器上开放的服务入口，相当于「门牌号下的具体房间」。
- **用户名、密码**：访问这台服务器的凭证，用于认证（有的代理不需要）。

## 什么是链式代理

链式代理是把**多个代理串起来**使用：

```text
你的设备 → 第一跳代理 → 第二跳代理 → 目标网站
```

流量先经过第一跳，再经过第二跳，最后到达目标网站。常见用法是：**第一跳用机场节点负责出海，第二跳用代理 IP 作为最终出口**，让目标网站看到的是代理 IP。

## 什么是出口 IP

**出口 IP** 是整条链路上最后一个代理的 IP，也就是目标网站最终看到的来源 IP。判断配置是否成功，就看出口 IP 是否等于你期望的那个代理 IP。
