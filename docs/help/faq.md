# 常见问题

## IP 纯净度/欺诈值/风控度

    每个社交平台都有自己的风控机制与数据库，风控是多维度的，并不只受 IP 地址影响，所谓纯净度只是一个参考，并不代表这个IP就一定能在你所经营的业务中表现好。
    例如某一个IP可能在一些检测网站中显示为极高风险，但因为从来没有在某个网站使用过，被你拿去运营该网站账号也能表现良好。
    有些IP能够得到大多数网站的认可，即使被标记为低风险，也不代表就一定不会被风控。

## 为什么不同 IP 检测网站显示的地区不同？

    不同网站的 IP 归属库数据不同，对同一 IP 可能显示不同地区。以多个权威站点的结果综合判断，不必纠结单个站点的差异。

## SOCKS5 和 HTTP 有什么区别？

    SOCKS5 能转发任意类型流量，通用性最强；HTTP 代理主要面向网页浏览场景。不确定时优先用 SOCKS5，但最终以服务商标注为准。

## 为什么填好了也不能联网？

    用户名或密码填写错误，或协议选错。重新核对服务商提供的账号信息和协议类型。
    
## 什么是链式代理？

    把多个网络串起来：流量依次经过多个节点，最后一个节点的 IP 就是出口 IP。常用于「机场节点出海 + 代理 IP 作最终出口」。

## 为什么连接成功却无法访问网站？

    连接成功只代表链路建立。可能原因：出口 IP 被目标网站限制、代理节点本身不可用、或目标网站对代理 IP 有风控。

## 为什么最终出口 IP 不正确？

    通常是链式关系的顺序或前置代理设置错了，导致流量没有经过预设的最后一个节点。请核对前置代理节点与出口代理 IP 的顺序。

## 代理连接成功是否代表第三方网站一定允许访问？

    不代表。连接成功只是链路通了；第三方网站是否允许该出口 IP 访问，取决于平台的风控和地区策略，属于另一回事。
