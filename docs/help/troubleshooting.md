# 代理连接失败？按照这三步检查

连接失败时，按顺序排查这三步，绝大多数问题都能定位。

## 第一步：检查代理信息

- IP、端口、用户名、密码是否**逐字符**填对了（注意 `0` 和 `O`、`1` 和 `l`）。
- 协议是否选对：服务商标注是 **SOCKS5** 还是 **HTTP**，客户端里必须一致。
- 用户名、密码是否填反，或漏了大小写。

## 第二步：检查代理连接、端口和认证

在电脑上用 PowerShell 测试端口是否可达（这里只是测端口，不是客户端教程）：

```powershell
Test-NetConnection -ComputerName <代理IP> -Port <端口>
```

- 结果 `TcpTestSucceeded : True` → 端口可达，继续看认证；
- 结果 `TcpTestSucceeded : False` → 网络或服务器问题，检查 IP、端口是否正确。

::: warning 端口通 ≠ 一切正常
端口连通只说明「能连上服务器」，**不代表认证成功，更不代表整条代理链正常**。还要确认用户名密码正确，并验证最终出口 IP。
:::

## 第三步：检查代理链及最终出口 IP

1. 确认链式关系配置正确：第一跳（机场节点）和第二跳（代理 IP）的先后顺序、前置代理设置是否对。
2. 连接成功后，打开 IP 查询网站，看显示的 IP 是否等于你的代理 IP。
3. 若出口 IP 不对，说明链路或出口设置有问题，回到第二步对应教程核对。

## 常见报错

| 报错 | 含义 | 常见原因 |
| --- | --- | --- |
| Connection refused | 连接被拒绝 | IP 或端口错误、服务器未开放 |
| Connection timed out | 连接超时 | 网络不通、防火墙拦截、IP 端口不对 |
| Authentication failed | 认证失败 | 用户名或密码错误、协议选错 |
