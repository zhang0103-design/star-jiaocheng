# 代理连接失败？按照这三步检查

连接失败时，按顺序排查这三步，绝大多数问题都能定位。

## 1. 检查代理信息

- IP、端口、用户名、密码是否**逐字符**填对了（注意形似的数字与字母，以及大小写区分，如： `0` 和 `O`、`1` 和 `l`）。
- 协议是否选对：服务商标注是 **SOCKS5** 还是 **HTTP**，客户端里必须一致。
- 用户名、密码是否填反，或漏了大小写。

## 2. 检查海外网络与客户端模式

- 确认你的**海外网络（机场节点）本身正常**：单独连接机场节点，看能否正常访问海外网站。
- 确认客户端是否开启了 **TUN 模式 / 虚拟网卡**等选项。开启后由客户端接管全局流量。
- 如果客户端**没有** TUN 模式或虚拟网卡功能，尝试把模式切换为**全局模式**，避免流量没有走代理。

## 3. 检查代理链及最终出口 IP

1. 确认链式关系配置正确：第一跳（机场节点）和第二跳（代理 IP）的先后顺序、前置代理设置是否对。
2. 连接成功后，打开 IP 查询网站，看显示的 IP 是否等于你的代理 IP。
3. 若出口 IP 不对，说明链路或出口设置有问题，回到对应步骤核对。

## 常见报错

| 报错 | 含义 | 常见原因 |
| --- | --- | --- |
| Connection refused | 连接被拒绝 | IP 或端口错误、服务器未开放 |
| Connection timed out | 连接超时 | 网络不通、防火墙拦截、IP 端口不对 |
| Authentication failed | 认证失败 | 用户名或密码错误、协议选错 |
