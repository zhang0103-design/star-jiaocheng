# iPhone / iOS 链式代理配置

本页演示使用 **Shadowrocket**（iOS 端常用代理客户端）。不同客户端的界面和选项可能不同，请以你实际使用的客户端为准。

## 链式代理是怎么工作的

```text
手机
 ↓
第一跳代理（机场节点 · 负责出海）
 ↓
第二跳代理（代理 IP · 最终出口）
 ↓
目标网站
```

- **第一跳**：机场节点，负责把流量「送出海」。
- **第二跳**：代理 IP，负责作为最终出口。
- **出口 IP**：目标网站最终看到的 IP，等于第二跳的代理 IP。

## 操作前准备

1. **代理 IP 信息**：IP、端口、用户名、密码。
2. **机场订阅链接**：用于第一跳出海。

## 操作步骤（Shadowrocket 演示）

### 1. 导入机场节点（第一跳）

打开 Shadowrocket，点「扫描二维码」或「添加节点」，导入你自己的机场订阅。

::: danger 这一步最关键，别看到二维码就晕
视频第 **4 秒到第 11 秒**演示的是**导入你自己的机场节点**（扫描机场的订阅二维码）。请记住：这里扫的二维码来自**你购买的机场**，不是代理 IP。只有先导入机场节点，后面才能用它做「第一跳」出海。
:::

### 2. 添加代理 IP（第二跳）

添加节点，填入你的代理 IP 信息（地址、端口、用户名、密码）。

::: danger 协议别照抄视频
视频里演示时选择了 **HTTP** 协议，这只是示例。**协议要根据你自己的代理 IP 服务商提供的信息来选**（是 SOCKS5 还是 HTTP），不要机械模仿视频里的选择，否则会连接失败。
:::

### 3. 配置链式关系

在代理 IP 节点上设置「代理通过」，选择第一跳的机场节点。这样流量先经机场出海，再经代理 IP 出口。

### 4. 连接并测试出口 IP

连接后打开 IP 查询网站（如 ipinfo.io / ip2location.com），确认显示的 IP 等于你的代理 IP。
