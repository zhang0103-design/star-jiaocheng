## 新手入门路线

按下面顺序阅读，最快上手：

1. [了解代理 IP 基础](/guide/proxy-basics) —— 认识 IP、端口、用户名、密码和 SOCKS5。
2. [快速开始](/guide/quick-start) —— 获取代理信息并确认协议。
3. [配置手机链式代理](/mobile/android-chain) —— 安卓 / iOS 按截图逐步操作。
4. [测试与排查](/help/troubleshooting) —— 验证最终出口 IP 是否一致。
